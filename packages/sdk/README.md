# @imageryx/sdk

Framework-agnostic TypeScript client SDK for the Imageryx API.

## Phase 1 status

This package is a placeholder. It contains no HTTP client or API methods
yet — only package metadata so the workspace resolves, and so later phases
have a stable import path (`@imageryx/sdk`) to build against.

## Deferred to a later phase

- Typed client built on `@imageryx/contracts`.
- Upload, transform, and delivery URL builder methods.
- `@imageryx/angular` will wrap this SDK for Angular consumers.
